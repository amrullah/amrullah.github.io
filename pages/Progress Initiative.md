- # Initiative
    - ## Upskillers group
        - ### Agenda:
            - Increase knowledge
            - Be in a position to share knowledge with others.
            - Pursue promotion.
        - ### Long term vision
            - Create a pool of strong and highly accomplished individuals in positions of influence.
        - ### Preferred tools
            - PKM (or any way to build a knowledge base) + github (archival/backup). (Tech bias)
        - ### What kind of content is allowed:
            - what resource (book, course, video) you have started consuming (should be related to professional growth)
            - Progress updates
            - Conversation as an accountability partner (looking for one, asking for updates) (but conversations on the subject itself should be taken to 1:1 DM)
            - Congratulate and encourage those who post updates about their learning.
            - Help questions about PKM or any storage / archival mechanisms
        - ### Challenges:
            - Not everyone can operate git (alternatives: cloud storage, con: inability to share progress )
            - Not sure how large repos github allows.
            - If repo is private (for copyright reason), how can they share the progress?

- [[Z Ordering]] ((68e4ceb0-2d86-4cf6-8560-caf3b8c50a58))
    - A technique independent of [[Delta Lake]] that is used for co-locating related data points (increasing [[Data Locality]] in the [[Hard Disk Drive]] )
    - Exploit Sequential Disk Access
    - It reads the data from the [[Disk]] and it applies a logic and then re-writes to [[Disk]] such that the reads are faster
        - The logic is, For example, if Column A and Column B are heavily used in the query, then write the data of the [[Delta Table]] to the [[Disk]] in a way that is conducive for read speed
    - What is [[Z Ordering]] ? ((68e4d18b-c395-4a2e-a305-34862e7fc2b4))
        - Initially you won't know the query patterns, but after some time, some insight can be gained and the data can be re-written to disk, to optimize for the majority use-case columns

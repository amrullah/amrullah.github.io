- [[Muhammad Hasan Khan]]
    - I have a tendency to overwork when:
      tags:: Engineering Manager
        - 1. I'm enjoying solving the problem
        - 2. There is an element of suspense. I have an idea what needs to be done but don't know exactly the details so there is some discovery to be done.
        - 3. The problem is not so hard that I'll not make progress at all but it isn't so easy either that there is no challenge at all.
        - 4. I'm learning something every day by working on the problem.
        - 5. I picked the problem myself rather than it being imposed on me.
        - 6. There are multiple ways to solve the problem. Working on the problem is like exploring a graph of solutions.
        - 7. I have the freedom to work on it in an official capacity.
        - When all of the above are true, work is like playing a video game and time flies. It's hard to stop because it feels like every minute away from the PC is a lost opportunity to make progress.
    - Status:
      tags:: Engineering Manager
        - High stress results in high cortisol levels.
        - High cortisol levels can affect our problem solving ability besides causing many other illnesses.
        - This means in high stress environments, people are more likely to make poor choices and take longer to complete tasks.
        - If the stress increases because the task is taking longer then the task is likely to take even more time to finish due to increased number of mistakes made.
